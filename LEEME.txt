CONTROL DE TRABAJOS — versión inicial

Incluye:
- Listado de trabajos ordenado por fecha, filtros por estado.
- Alta y edición de trabajos.
- Registro de ingresos y gastos por trabajo.
- Cálculo de totales y beneficio.
- Resumen general.
- Exportación JSON y CSV y restauración de copia JSON.

IMPORTANTE:
Esta app guarda los datos en localStorage del navegador. Antes de usarla para datos reales, prueba la exportación/restauración y guarda copias de seguridad frecuentes. No es software de contabilidad fiscal y no sustituye la gestión oficial de facturas/impuestos.

CÓMO ABRIR:
1. Para una prueba rápida, abre index.html desde un alojamiento web o un entorno que permita servir archivos web.
2. Para instalarla como PWA en iPadOS, debe estar servida desde HTTPS (no basta con abrir un archivo local).
3. En Safari, abre la URL publicada y pulsa Compartir > Añadir a pantalla de inicio.
4. La instalación PWA y el funcionamiento sin conexión dependen del alojamiento y de la versión de Safari/iPadOS.

El paquete no incluye servidor ni sincronización entre dispositivos.


CAMBIOS DE LA VERSION PARA REFORMAS
- Ficha de obra con cliente, teléfono, dirección, fechas, presupuesto y cinco estados: Pendiente, En curso, Terminada, Facturada y Cobrada.
- Gastos clasificados en Materiales, Gasolina, OTA, Parking, Herramienta, Comida y Otros.
- En cada gasto puedes indicar si tienes factura del proveedor. No se adjuntan PDF.
- En materiales, usa la descripción para indicar qué compraste y el campo tienda/proveedor para indicar dónde.
- Los datos que ya estuvieran guardados se mantienen; los estados antiguos se convierten a los nuevos.
- Después de actualizar los archivos en GitHub Pages, puede ser necesario cerrar y volver a abrir la aplicación o actualizarla desde Safari.


APARTADO DE FOTOS (versión actualizada)
- Cada obra tiene una pestaña Fotos para elegir una imagen de la galería o hacer una foto con el iPad.
- Cada foto se guarda con fecha y descripción, y se puede ampliar o eliminar.
- Las fotos se almacenan localmente en este navegador/dispositivo mediante IndexedDB; no se suben a internet.
- Las copias JSON incluyen las fotos. Como pueden ocupar bastante, guarda las copias en Archivos y comprueba que se descargan correctamente.
- Las imágenes se reducen automáticamente para ahorrar espacio. Aun así, no guardes una cantidad ilimitada de fotos y haz copias de seguridad frecuentes.
